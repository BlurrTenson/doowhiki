# Dowhiki
A fork of [dooing](https://github.com/atiladefreitas/dooing) with modifications to support my workflow. By no means is this fork supported, use the real tool. 

# Changes
* option in config to store scratchpad notes as files rather then inline. 
* changes to delete and some other functions to support the above. 

# Why?
Because I quite like using the tool as a wiki for projects. By using separate files I can attach notes to each task and then commit everything. In git the commit then contains the files and changes so it's easy to see what note is associated with what change and to track how the knowledge base evolves
